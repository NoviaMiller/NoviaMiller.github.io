# 你好，我的第一篇笔记 👋

欢迎来到我的笔记库！这里记录我学习与生活的点点滴滴。

## 关于这个笔记库

这是一个 **渲染 Markdown 的笔记库**，采用动森（Animal Crossing）风格的 UI 设计，温暖治愈。

### 主要功能

- 支持 Markdown 渲染
- 支持明暗主题切换
- 左侧目录（TOC）自动生成

## 一段代码示例

```js
// 一个简单的问候函数
function greet(name) {
  return `你好，${name}！`
}

console.log(greet('Novia'))
```
