# Markdown 语法速查

一份常用的 Markdown 语法快速参考，写作时随手查阅。

## 标题

使用 `#` 表示一级标题，`##` 表示二级标题，以此类推。

## 强调

- **加粗** 使用 `**加粗**`
- *斜体* 使用 `*斜体*`
- ~~删除线~~ 使用 `~~删除线~~`

## 列表

### 无序列表

- 苹果
- 香蕉
- 橙子

### 有序列表

1. 第一步
2. 第二步
3. 第三步

## 链接

[GitHub](https://github.com) —— 行内链接。

## 引用

> 好记性不如烂笔头。

## 代码

行内代码：`const x = 1`

```python
def hello():
    print("Hello, world!")
```

## 分割线

使用 `---` 即可画一条分割线。
