# 提示词

这是我的github pages项目，请你为我编写代码，使这个项目成为一个**渲染markdown的笔记库** 

## 风格

使用下面这个vue组件进行开发！保持风格一致

https://github\.com/guokaigdg/animal\-island\-vue\.git

## 架构

顶部是导航栏，永远固定不变。

导航栏有这三块内容，居中显示：**首页、笔记、项目** ，点击后跳转到对应页面。

右上角是一个明暗切换的按钮 以及 我的github头像（点击可以进入我的github主页）

左上角显示现在的时间，hh：mm格式

下面介绍各个导航栏：

### 首页

暂时不做过多处理，进入后只有一段自我介绍

### 笔记

点击后跳转页面，进入**笔记陈列页面** 

要求每一行一种笔记，左边是图片（未上传则自动选择默认图片），右边从上到下是标题（大粗字体）、简介（小字体）

点击**笔记** ，内部才是重头戏

- 笔记内容呈现

参考这个页面的呈现格式以及布局手段，方便后续md扩展：https://hello\-agents\.datawhale\.cc/\#/

总体不要偏移原始**风格** 的要求

### 项目

暂时不开发，点击会跳出弹窗：敬请期待
